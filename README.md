# cyber-code-review-skill

Workspace for the organisation-wide security code-review skill (Agent Skills format).

Plan, research extracts, and skill development live here. The survey of existing
security code-review implementations (awesome-claude-skills, oh-my-pi, Anthropic
skill libraries, OWASP/NIST/CodeQL sources) is captured in the firstmate home at
data/cyber-code-review-scout/.

Scope of the skill's review criteria: input validation, authNZ (authN and authZ),
secret hygiene, crypto, software supply chain, and logging/errors/audit.
